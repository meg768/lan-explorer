# LAN Explorer Help

<img src="images/app-icon.png" alt="LAN Explorer app icon" width="96" height="96">

Find devices on your local network and inspect their services from a native macOS app. LAN Explorer helps you identify computers, Raspberry Pi devices, smart-home servers, printers, and other reachable devices.

Requires **macOS 14 or later**. Network discovery works without configuring SSH.

## Start

- **[Getting Started](getting-started.html)** — Allow local-network access, run a scan, and select a device.
- **[Devices and Services](devices.html)** — Understand addresses, names, vendor hints, service ports, and scan results.

## Inspect and troubleshoot

- **[SSH Access](ssh.html)** — Save a private key and device usernames to read detailed system information.
- **[Troubleshooting](troubleshooting.html)** — Resolve missing devices, network permissions, and SSH connection problems.

## Support and privacy

- **[Support](support.html)** — Ask a question or report a problem through GitHub Issues.
- **[Privacy Policy](privacy.html)** — How LAN Explorer handles network information, SSH keys, and local settings.
